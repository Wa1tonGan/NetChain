# Demo signing keys

Throwaway ed25519 keypairs generated by `scripts/provision-demo-identity.mjs`
for the hackathon demo only. They are committed so that anyone can re-sign or
verify fixtures offline; **never reuse them outside the demo.**

| File | Owner | Used for |
| --- | --- | --- |
| `provider-{a,b,c}.private.pem` | Provider agents | Signing `Provider Offer` payloads |
| `provider-{a,b,c}.public.pem` | Anyone verifying | Verifying offers (also embedded in each profile) |
| `buyer.private.pem` | Rescue Agent (Person 2) | Signing the buyer side of the agreement |
| `buyer.public.pem` | Person 3 | Verifying `buyerSignature` before creating the Sui commitment |

Regenerating keys invalidates all signed fixtures — run
`node scripts/generate-fixtures.mjs` afterwards.
