## New traps from THIS session (previous traps in the 08-30 handoff still apply)

- **`npm test` must load `.env`** (it does via `--env-file-if-exists`). Bare
  `node --test` without it → fixture regen bakes `0xPLATFORM_DEMO` placeholder →
  3 spurious fee-split failures. Not a code bug; rerun with `npm test`.
- **`process.loadEnvFile` does NOT override already-set env vars** — prefix wins:
  `SUI_NETWORK=testnet node scripts/…` beats whatever `.env` says.
- **Gateway caches per `incidentId` + offers expire 60 s** (`OFFER_TTL_MS`): reusing
  an incident id replays a stale envelope → `voucher expired`. The driver mints a
  unique suffix per run; pin with `SUI_P2_INCIDENT_ID` only for controlled replay.
- **Use the ASYNC portal route** `POST /recovery/intents` (202 + record). The sync
  `/v1/recovery` route keeps no incident record → P2 settlement callback 404s.
- **Integration driver keeps its OWN ledger** `events/integration-<net>.jsonl` —
  demo-era rows in `reliability-events.jsonl` would block a fresh-pool proof with
  "nonce already SETTLED". Deleting the integration ledger is safe.
- **`getBalance` cannot see `Balance<T>` inside a shared object** — a funded pool
  can read as 0 USDC. The real test is a commit, not a balance query.
- **Walrus SDK 1.2.21 + gRPC client**: `WalrusClient` accepts `SuiGrpcClient` fine.
  Use `writeBlob`/`readBlob` (quilt `getFiles` on a blobId returns raw quilt bytes;
  `.json()` fails). `deletable` is REQUIRED (`false` for evidence).
  `exchange_all_for_wal` takes NO typeArguments (VMVerification error if you pass
  one); exchange pkg `0x82593828…81ef9f`, exchange id = `exchangeIds[0]` of the
  testnet config.
- **Node ≥ 22 recommended** for `process.loadEnvFile` (Node 20.x lacks it — the
  repo's launcher scripts would skip .env silently; current machine runs 22.23.1).
